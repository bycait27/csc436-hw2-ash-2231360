$ dig "@1.1.1.1" depaul.edu SOA +noall +answer
====================================================================================

depaul.edu.             14400   IN      SOA     ns1.depaul.edu. networks.depaul.edu. 10 14400 1800 1209600 900

====================================================================================

The last field of the SOA (900) is the minimum negative-cache TTL. This tells the operator that 
there was a failed DNS lookup and it won't keep trying the server again and again.

====================================================================================

www.depaul.edu acts as an alias and points to 22b8cde06cfddd89.vercel-dns-013.com. The 
CNAME has a long TTL because the alias rarely changes, but the target A TTLs are shorter 
because the host servers can change.

$ dig "@1.1.1.1" depaul.edu MX +noall +answer
====================================================================================

depaul.edu.             394     IN      MX      0 depaul-edu.mail.protection.outlook.com.

====================================================================================

Mail delivery uses a hostname instead of a raw IP address because A records already 
handle this. MX records allow mail routing to adapt to any changes in the A record.
